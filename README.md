# Arcu

Alternative to macOS Spotlight.

**/ɑɹkuː/**
from Vestibulum arcu, latin for Spotlight.

## Dev Instructions

### Get started
1. Install [Node](https://nodejs.org/en/)
2. Run `npm install` to get the dependencies of the project.
3. Follow [the instructions for setting up Neon](https://neon-bindings.com/docs/getting-started/).

### Commands

* `npm run build`: Build the Rust part of the app.
* `npm run start`: Build and Start the app.
* `npm run dist`: Build the app.
* `npm run pack`: Build unpacked dir. Useful to test.
