# Arcu

Alternative to macOS Spotlight.

**/ɑɹkuː/**
from Vestibulum arcu, latin for Spotlight.

## Dev Instructions

### Get started
1. Install [Node](https://nodejs.org/en/)
2. Run `npm install` to get the dependencies of the project.
3. Run `npm run rebuild` to fix native dependencies.

### Commands
- `npm run rebuild` - Fix native dependencies. If you get an error about "NODE_MODULE_VERSION"
- `npm run start` - start the app (VSCode debugging works too).
- `npm run dist` - install dependencies.
